# Practical 10: Custom Exceptions – Banking Transaction

## Aim
To implement exception handling in a banking transaction using C++.

## Objectives
- Understand exception handling.
- Handle invalid transactions.
- Prevent withdrawal beyond the available balance.

## Concepts Used
- try and catch
- throw
- Exception Handling
- Banking Transactions

## Program Description
This program simulates a bank account with a balance of 5000. It allows withdrawals and handles invalid amounts or insufficient balance using exceptions.

## Software Requirements
- Visual Studio Code
- C++ Compiler (G++)

## Result
Successfully implemented exception handling for banking transactions in C++.
