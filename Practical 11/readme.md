# Practical 11: CSV Student Records Using File I/O

## Aim
To store and retrieve student records using file handling in C++.

## Objectives
- Understand file input and output.
- Create and write data into a CSV file.
- Read and display stored records.

## Concepts Used
- File Handling
- ifstream
- ofstream
- getline()
- CSV Format

## Program Description
This program creates a CSV file named students.csv and stores student names, roll numbers, and marks. It then reads and displays the stored records.

## Software Requirements
- Visual Studio Code
- C++ Compiler (G++)

## Result
Successfully created, stored, and retrieved student records using CSV file handling in C++.
