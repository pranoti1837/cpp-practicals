# Practical 12: Student Portal Management System

## Aim
To develop a Student Portal Management System using C++.

## Objectives
- Provide a basic login system.
- Add and display student records.
- Search student details using roll number.
- Store records permanently using file handling.

## Features
1. Admin Login
2. Add Student
3. Display Students
4. Search Student
5. Logout

## Concepts Used
- Classes and Objects
- Encapsulation
- Conditional Statements
- Loops and Switch Case
- File Handling
- ifstream and ofstream
- String Handling

## Program Description
The Student Portal is a menu-driven C++ application. The admin logs in using demo credentials and can add student details, display all records, and search for students by roll number. Student information is stored in a text file named students.txt.
