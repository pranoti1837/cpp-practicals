# Practical 3: Constructors and Rule of Five

## Aim
To understand constructors, copy constructors and destructors in C++.

## Objective
To demonstrate different types of constructors and object destruction using a Student class.

## Concepts Used

1. **Default Constructor:** Initializes an object without arguments.
2. **Parameterized Constructor:** Initializes an object with given values.
3. **Copy Constructor:** Creates a new object by copying another object.
4. **Destructor:** Automatically runs when an object is destroyed.
5. **Rule of Five:** Defines five special member functions used for safe resource management.

## Program Description
The program creates three student objects using default, parameterized and copy constructors. It displays their details and demonstrates destructor execution.

## Software Used
- Visual Studio Code
- C++ Compiler (G++)

## Compile and Run
```bash
g++ main.cpp -o student
./student
```

## Result
Successfully implemented different types of constructors and a destructor in C++.
