
# Practical 7: Compile-Time Polymorphism

## Aim
To implement compile-time polymorphism using function overloading in C++.

## Objectives
- Understand function overloading.
- Use the same function name with different parameters.
- Understand compile-time polymorphism.

## Concepts Used
- Classes and Objects
- Function Overloading
- Compile-Time Polymorphism

## Program Description
This program uses a Calculator class with three overloaded add() functions. They perform addition of two integers, two decimal numbers, and three integers.

## Software Requirements
- Visual Studio Code
- C++ Compiler (G++)

## Result
Successfully implemented compile-time polymorphism using function overloading in C++.
