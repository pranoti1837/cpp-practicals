# Practical 8: Singleton Design Pattern

## Aim
To implement the Singleton Design Pattern in C++.

## Objectives
- Understand the Singleton Design Pattern.
- Ensure that only one object of a class is created.
- Control object creation using a static member function.

## Concepts Used
- Classes and Objects
- Static Data Members
- Static Member Functions
- Private Constructor
- Design Patterns

## Program Description
This program creates a Singleton class with a private constructor and a static getInstance() function. It ensures that repeated calls return the same object.

## Software Requirements
- Visual Studio Code
- C++ Compiler (G++)

## Result
Successfully implemented the Singleton Design Pattern in C++.
