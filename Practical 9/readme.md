# Practical 9: Generic Stack Using Templates

## Aim
To implement a generic stack using class templates in C++.

## Objectives
- Understand class templates.
- Implement stack operations.
- Use templates with different data types.

## Concepts Used
- Class Templates
- Stack
- Push Operation
- Pop Operation
- Display Operation

## Program Description
This program implements a stack using a class template. It performs push, pop, and display operations using an integer stack.

## Software Requirements
- Visual Studio Code
- C++ Compiler (G++)

## Result
Successfully implemented a generic stack using templates in C++.
