# C++ Practicals

## Practical 01: GitHub Setup and C++ Fundamentals

### Objective
To understand basic C++ programming concepts, data types, variables, constants, operators, and input/output statements.

### Program
The program accepts a student's name and marks in two subjects, calculates the total and average, and displays the result.

### Concepts Used
- Data types and variables
- Constants
- User input using `cin` and `getline()`
- Output using `cout`
- Arithmetic operators
- Relational operators
- Logical operators
- Conditional statements

### How to Compile
```bash
g++ main.cpp -o practical01
```

### How to Run
```bash
./practical01
```
