# Practical 2: Classes, Access Specifiers and Member Functions

## Aim
To understand classes, objects, access specifiers and member functions in C++.

## Objective
To create a BankAccount class that stores account details and performs deposit and withdrawal operations.

## Concepts Used
1. **Class:** A blueprint for creating objects.
2. **Object:** An instance of a class.
3. **Private:** Data members cannot be accessed directly outside the class.
4. **Public:** Members can be accessed through the object.
5. **Constructor:** Initializes object data.
6. **Member Functions:** Perform operations such as deposit, withdraw and display.

## Program Description
The program creates two bank account objects. It displays account details and performs deposit and withdrawal operations. It also checks whether the entered amount is valid.

## Software Used
- Visual Studio Code
- C++ Compiler (G++)

## Compile and Run
```bash
g++ main.cpp -o bankaccount
./bankaccount
```

## Result
The BankAccount class was successfully implemented using constructors, private and public access specifiers, and member functions.
